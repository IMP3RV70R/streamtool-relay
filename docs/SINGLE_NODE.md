# Local single-node development

`make control-up` starts a SQLite API/controller, mTLS Docker Agent, authenticated
MediaMTX edge and local RTMP receiver. The managed worker is created per session.
This is a development stack, not the production installer.

Open `http://localhost:18080/dashboard`. Set up the sole owner using
`infra/local/secrets/setup_token`; then copy the automatically prepared source credentials
and configure up to eight outputs. Local destination exception `receiver` belongs only
to development configuration. SRT is at UDP 18890, RTMP at TCP 11935. Public URLs and
local ports are configurable through Compose. Local certificates are generated by
`tests/control/certificates.sh`.

The control fixture defaults to node UUID `00000000-0000-4000-8000-000000000002`;
the installed self-hosted node uses UUID ending `001`. Its node inventory is generated
in `.artifacts/control-media-nodes.json`. Set `CONTROL_TEST_NODE_ID` consistently
for setup, Compose, acceptance and cleanup when using another test node. Setup and
cleanup refuse the installed node ID so orphan recovery on a shared Docker daemon
cannot confuse this fixture with the installed application. Database volumes and
credentials remain preserved by `make control-down`.

SQLite persists sessions, hashes/encrypted keys, fallback content/generations and
controller fencing. Agent fencing is independent and persists restart adoption.
The local Agent deliberately runs development network policy; namespace firewall/
traffic-policing production acceptance requires a Linux host.

A common encoder normalizes source video to the output quality, default720p30/3000 kbps.
Source/fallback switching preserves the output connection. Optional 1080p60 and
fractional FPS are configurable before streaming. Video fallback is decoded/looped
without preparation; uploaded audio becomes silence. NO_SIGNAL without automatic
fallback sends black video and silence. Whole-server failure requires a new connection.

```sh
make control-e2e         # media, API/Agent adoption, SQLite/control restart,
                        # worker crash, edge restart, stop/no resurrection
make control-video-e2e   # actual decoded 1080p60, B-frames, silent moving MP4
make control-db-test     # temporary SQLite tests with race detector
make users-test
make control-down       # removes containers; preserves database/secrets
```

The authenticated `/operator` page and bearer operator API are local engineering
interfaces. Production Caddy blocks them. Owner routes are the public product:
[API contract](../contracts/user-api.md). The API and worker metrics require their
separate configured credentials; never expose Agent, edge control or worker ports.

See [self-host installation](SELFHOST.md) for the production deployment/package,
backup/update/restore behavior and remaining acceptance boundaries.
